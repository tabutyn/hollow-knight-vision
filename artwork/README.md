# Application icon

`app-icon-source.png` is a literal composite built from Hollow Knight's
installed `PlayerIcon.icns`. The original pixels remain unchanged outside the
right-eye overlay. `app-icon-monocle-overlay.png` is the transparent monocle
layer resized to 480×354 and placed at `+483+615` on the 1024×1024 original.
The remaining transparency is composited onto opaque white.

The compiled macOS and Windows icon files are derived from that composite.
